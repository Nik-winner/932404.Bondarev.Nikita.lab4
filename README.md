### Реализация script.js

- **Ввод/вывод:**
  - `prompt` — запрос имени пользователя;
  - `alert` — приветствие и итоговая сводка по отработанным часам;
  - `console.log` — вывод промежуточных и итоговых расчётов.
- **Условные конструкции:** проверка наличия имени, наличия недель с высокой нагрузкой, превышения суммы 50 часов.
- **Циклы:** поиск максимума, подсчёт суммы, фильтрация, подсчёт недель с малым участием.
- **Функции:**
  - `findMax(arr)` — возвращает максимальное значение массива;
  - `filterAbove(arr, threshold)` — возвращает элементы, большие заданного порога;
  - `calculateSum(arr)` — возвращает сумму элементов массива.
